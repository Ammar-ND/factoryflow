# FactoryFlow — Project Vision

FactoryFlow is a manufacturing workflow management system.

The system will manage:

- Products
- Machines
- Production lines
- Production orders
- Maintenance
- Quality checks
- Alarms and downtime
- Users and roles
- Reports and dashboards

The project will use ASP.NET Core for the backend, React + TypeScript for the frontend, and SQL Server for the database.

The main goal is to build a realistic manufacturing system using modern software architecture and development practices.
