# FactoryFlow — Business Requirements

FactoryFlow should allow users to:

- Manage products.
- Manage machines and production lines.
- Create and manage production orders.
- Monitor production status.
- Record machine downtime and alarms.
- Manage maintenance activities.
- Perform quality checks.
- View reports and dashboards.

## User Types

### Admin
Manages users and system settings.

### Production Manager
Creates and monitors production orders.

### Operator
Operates machines and updates production status.

### Maintenance Technician
Handles machine maintenance and failures.

### Quality Inspector
Performs and records quality checks.
